# Dual-Lens Audit (DLA) Experiment

This repository implements the synthetic experiments described in the research paper:

> *One Root, Two Failures: A Dual-Lens Audit Framework for Algorithmic Fairness and Adversarial Robustness in Indian AI Deployments*

## What it runs

### Experiment 1 - Proxy bias
- 40,000 synthetic applicants
- 30% disadvantaged group
- True merit depends only on income and credit history
- Historical labels contain a group-specific penalty
- Pincode is an 80%-accurate proxy for group membership
- Logistic regression
- 70/30 train/test split
- Five random seeds
- Measures DIR, EOD, proxy-AUC and counterfactual flip rate
- Compares a model with pincode against one where the proxy is removed

### Experiment 2 - Backdoor poisoning 
- Same synthetic population
- Gradient-boosting classifier
- 200 employer codes
- Employer code 199 is used as the planted trigger
- Poison rates: 0%, 0.1%, 0.5%, 1.0% of the training split
- 2,000 low-merit canary examples
- Trigger sweep tests all 200 employer codes
- Detection threshold: approval-rate shift > 20 percentage points
- Five random seeds

## Run

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux:
# source .venv/bin/activate

pip install -r requirements.txt
python dla_experiment.py
```

The script creates a `results/` directory containing:

- `fairness_seed_results.csv`
- `fairness_summary.csv`
- `poisoning_seed_results.csv`
- `poisoning_summary.csv`
- `trigger_detection_summary.csv`
- `experiment_metadata.json`
- `backdoor_poisoning.png`

## Research-integrity rule

Do not copy numerical results from an earlier draft or from an AI-generated answer. Use the numbers generated by this script after you run it, and keep the code/results as supplementary evidence.

The experiment is synthetic and demonstrates the behavior of the proposed gates. It does **not** establish that the same prevalence or effect sizes occur in real Indian lending systems.
